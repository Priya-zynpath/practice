# Theater Ticket Booking System

A Java Console Application developed using Object-Oriented Programming concepts for booking and managing theater seats.

## Features

- View Available Seats
- Book Tickets
- Cancel Tickets
- Dynamic Ticket Pricing
- Seat Availability Tracking
- Menu Driven System

## Technologies Used

- Java
- OOP Concepts
- 2D Arrays
- Scanner Class

## Concepts Implemented

- Classes and Objects
- Constructor
- Methods
- 2D Array Handling
- Loops
- Conditional Statements
- Menu Driven Programming

## Project Structure

```text
TicketBookingSystem/

```

## Seat Representation

```text
O = Available
X = Booked
```

## Ticket Pricing Logic

```text
Front Rows (1 & 2)  : Rs.250
Remaining Rows      : Rs.150
```
